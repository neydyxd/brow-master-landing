# 💄 Brow Master Landing Page

Современный и элегантный landing page для мастера по бровям Ирины, созданный с использованием React.

## 🌟 Особенности

- ✨ Современный и отзывчивый дизайн
- 📱 Адаптивная верстка для всех устройств
- 🎨 Интерактивные элементы и анимации
- 📞 Интеграция с телефоном и мессенджерами
- 📝 Форма записи на услуги
- 🖼️ Слайдер с работами
- 💰 Прозрачное отображение цен

## 🛠️ Технологии

- **React 18.2.0** - Основной фреймворк
- **React Icons** - Иконки
- **CSS3** - Стилизация
- **Responsive Design** - Адаптивность

## 🚀 Быстрый старт

### Предварительные требования

- Node.js (версия 14 или выше)
- npm или yarn

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/brow-master-landing.git
   cd brow-master-landing
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите проект в режиме разработки:
   ```bash
   npm start
   ```

4. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## 📦 Сборка для продакшена

```bash
npm run build
```

Это создаст оптимизированную сборку в папке `build/`.

## 🏗️ Структура проекта

```
src/
├── Components/
│   ├── App/          # Главный компонент приложения
│   ├── Header/       # Шапка сайта с навигацией
│   ├── About/        # Секция "О мастере"
│   ├── Slider/       # Слайдер с работами
│   ├── Price/        # Прайс-лист услуг
│   ├── Footer/       # Подвал сайта
│   ├── Popup/        # Модальное окно записи
│   ├── Navigation/   # Мобильное меню
│   └── Carousel/     # Карусель изображений
├── images/           # Изображения
└── vendor/           # Сторонние стили
```
